# 精灵图与播放器约定

本项目的最终素材为 `assets/clawdy-v2.png`。`pet.json` 是动作配置的权威来源。所有行列索引从 **0** 开始。

## 网格

图像为 1536×2288 RGBA PNG：8 列、11 行，每格 192×208。前 9 行为动作，后 2 行为视线。共 73 个有效格，15 个空白格。

取任意一格的源矩形：`x = column * 192`，`y = row * 208`，宽 192，高 208。保持宽高比和原有透明边距，不要对每帧分别紧裁剪、拉伸或重新居中，否则会破坏跳跃高度和脚部对齐。

屏幕坐标的 Y 轴向下。设鼠标相对宠物中心的偏移为 `(dx, dy)`：

```js
const degrees = (Math.atan2(dx, -dy) * 180 / Math.PI + 360) % 360;
const index = Math.round(degrees / 22.5) % 16;
const row = 9 + Math.floor(index / 8);
const column = index % 8;
```

鼠标接近中心时使用待机，避免方向频繁切换。演示采用 24 CSS 像素死区；你的宿主可自行调整。连续播放动作时，应逐帧使用各自时长。切换动作应重置计时器。

## ChatGPT 复用与自定义宿主

- ChatGPT 用户从 README 的公开分享链接领养。平台负责读取素材、触发动画、处理鼠标交互和保存启用状态。
- 自己编写播放器时，需要实现裁图、逐帧时序和鼠标方向选择。本仓库 `demo/index.html` 是可运行的参考实现。
- `pet.json` 是本项目的便携元数据格式，不代表公开的 ChatGPT 导入 API。
- 不要把作者账号内的宠物 ID 当作可导入资源；使用分享链接或仓库图像。此仓库不包含作者账号 ID、上传会话或带签名的临时下载地址。
